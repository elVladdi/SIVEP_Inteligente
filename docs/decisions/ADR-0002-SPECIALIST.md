# ADR-0002 — Decisión final del especialista

Estado: **Aceptada**. Fecha: 2026-11-21.

## Decisión
El sistema ofrece antecedentes, ranking, explicaciones y alertas. La valoración y las actuaciones administrativas, incluida la evaluación de duda razonable, competen al especialista conforme a la normativa aplicable.

## Consecuencias
Todas las recomendaciones deberán explicar procedencia, comparabilidad, limitaciones y datos que requieren validación. No calcular un valor en aduana definitivo automáticamente a partir de promedios o rankings.
