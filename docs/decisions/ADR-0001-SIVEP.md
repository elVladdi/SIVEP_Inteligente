# ADR-0001 — SIVEP como fuente primaria

Estado: **Aceptada**. Fecha: 2026-11-21.

## Decisión
Utilizar SIVEP como base histórica prevista. Se dispondrá del formato B de las DAM peruanas, sujeto a habilitación institucional y constatación del esquema real.

## Consecuencias
Integrar y mejorar calidad, comparabilidad y trazabilidad del histórico en lugar de construir una base paralela pública. No suponer que todo valor declarado fue validado; diferenciar estados de los valores según las fuentes verificadas.
