# Registro de decisiones (ADR)

Toda decisión material se registra en archivo independiente con estado, fecha, contexto, alternativas, decisión, consecuencias y evidencia. Las modificaciones se realizan mediante ADR nuevo o revisión explícita.

- ADR-0001 — SIVEP como fuente primaria: **aceptada**.
- ADR-0002 — Decisión final del especialista: **aceptada**.
- ADR-0003 — Coordinación multiagente y registro obligatorio de prompts/respuestas: **aceptada**.
- ADR-0007 — Enrutamiento bidireccional de prompts y respuestas entre agentes: **aceptada**.
- ADR-0006 — Entrada por ruta y respuesta completa documentada: **aceptada**.
- ADR-0005 — Continuidad entre sesiones mediante checkpoints: **aceptada**.
- ADR-0004 — Familia piloto y nivel arancelario: **pendiente**.

Los ADR no implican aprobación de accesos a datos ni de interpretaciones jurídicas sin verificación competente.
