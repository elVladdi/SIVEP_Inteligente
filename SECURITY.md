# Seguridad, confidencialidad y publicación

Este repositorio es público. **No publicar datos reales de SIVEP ni del formato B de DAM**, registros individualizables, identidades de operadores, precios vinculados a declaraciones, documentación interna, consultas con información restringida, credenciales, tokens, llaves, embeddings o modelos derivados de datos no autorizados.

## Registro de interacciones IA
La obligación de registrar todos los prompts y respuestas no autoriza divulgación de datos. Usar modo PUBLICABLE únicamente tras revisar texto completo. Para contenido restringido, registrar en GitHub metadatos y referencia a la ubicación institucional autorizada; el original debe custodiarse en entorno aprobado con acceso restringido. No enviar información real a proveedores externos de IA sin autorización expresa y evaluación de seguridad.

No registrar pensamientos internos no visibles o instrucciones confidenciales de proveedor. Para incidentes de exposición accidental, contactar al equipo de seguridad institucional y tratar el historial de Git como potencialmente replicado. Eliminar un commit no garantiza eliminación de copias.
