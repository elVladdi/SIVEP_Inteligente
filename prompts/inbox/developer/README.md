# Buzón de prompts de tarea: developer

Este directorio almacena **prompts completos de tareas dirigidas al rol `developer`**, emitidos por cualquiera de los otros dos agentes.

Al iniciar sesión:
1. Leer el prompt permanente de rol en `prompts/DEVELOPER.md`, `AGENTS.md` y `docs/operations/ROUTING_PROTOCOL.md`.
2. Consultar `prompts/ROUTING_INDEX.md`, localizar solo solicitudes autorizadas (**READY**) y validar issue/PR, SHA y alcance.
3. Registrar recepción y actividad, producir respuesta íntegra en `docs/ai-logs/`, publicar, verificar y actualizar el índice.
4. Si el resultado exige acción de otro rol, crear otro prompt en el **buzón del destinatario**.

No hay ejecución automática por depositar archivos. Los ejemplos van en `prompts/examples/`, no en este buzón. No subir información restringida.
