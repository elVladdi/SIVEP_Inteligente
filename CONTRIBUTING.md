# Colaboración

1. Crear o tomar un issue con objetivo, alcance, criterios de aceptación, riesgos y datos permitidos.
2. Trabajar en rama feature/, research/, fix/ o docs/.
3. Para cada interacción de cualquiera de las tres IA: registrar prompt + respuesta, incluyendo iteraciones, en docs/ai-logs/ siguiendo su README.
4. Adjuntar al PR pruebas ejecutadas, enlaces a registros IA, limitaciones y decisiones solicitadas.
5. Solicitar auditoría independiente y revisión humana; decisiones metodológicas importantes requieren ADR.
6. Fusionar solo después de atender observaciones y recibir aprobación del responsable del proyecto.

El repositorio es público. Revisar SECURITY.md antes de compartir contenido. La licencia del código está pendiente de aprobación.
